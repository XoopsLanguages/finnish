Apua: Profiili

-----Ohjesisältö ----------

KUVAUS

Profiilimoduuli on tarkoitettu mukautettujen käyttäjäprofiilikenttien hallintaan.

ASENNA/POISTA

Erikoistoimenpiteitä ei tarvita, noudata tavallista asennusprosessia – pura /profile-kansio ../modules-hakemistoon. Asenna moduuli kohdasta Admin -> System Module -> Modules.

Yksityiskohtaiset ohjeet moduulien asentamisesta ovat saatavilla osoitteessa XOOPS-käyttöopas

KÄYTTÖOHJEET

Tämän moduulin määrittäminen edellyttää:

  • Määritä moduulin asetuksesi (katso "Asetukset") ja valinnaisesti Profiililohko, jos aiot käyttää sitä (katso "Blocks").
  • Muokkaa olemassa olevia luokkia tai lisää uusia.
  • Muokkaa olemassa olevia kenttiä tai lisää uusia. Täällä voit määrittää, mitkä kentät ovat näkyvissä missä luokassa ja ovatko ne näkyvissä käyttäjän rekisteröinnin yhteydessä.
  • Määritä rekisteröintivaiheiden järjestys.
  • Ja lopuksi voit määrittää käyttöoikeudet yksittäisille kentälle - mitkä ovat muokattavissa, mitkä haettavissa.

Roskapostin estotoimenpiteet

Minimoi roskapostirekisteröinnit seuraavasti:

  • mene järjestelmänvalvojan Protector-moduuliin, valitse Asetukset ja sitten alareunassa tämä vaihtoehto: "Lopeta foorumi roskaposti" Tarkistaa POST-tiedot www.stopforumspam.com-tietokantaan rekisteröityjen roskapostittajien varalta.
    Aseta asetukseksi "Ban the IP (no limit)"

  • tiedostossa /class/captcha/config.php, varmista, että tilaksi on asetettu "teksti":

    return $config = array(
    'disabled' => false, // Poista CAPTCHA käytöstä
    'mode' => 'teksti', // oletustila, voit valita 'teksti', 'kuva', 'recaptcha' (vaatii api-avaimen)
    'name' => 'xoopscaptcha', // captcha-nimi
    'skipmember' => true, // Ohita jäsenten CAPTCHA-tarkistus
    'maxattempts' => 10, // Enimmäisyritysten määrä jokaisessa istunnossa
    );

  • Siirry Profiili-moduulissa kohtaan Admin ja perusvaiheessa, joka sijaitsee osoitteessa:
    /modules/profile/admin/step.php?id=1
    aseta "Tallenna pysäytyksen jälkeen" arvoksi "Ei"


  • Aseta Profiiliasetuksissa "Käytä Captchaa toisen rekisteröintivaiheen jälkeen" -asetukseksi "Kyllä" (se on oletusarvo)
