-----Ohjesisältö ----------

KUVAUS

PM-moduuli on tarkoitettu käyttäjien väliseen yksityisviestintään

ASENNA/POISTA

Erikoistoimenpiteitä ei tarvita, noudata tavallista asennusprosessia – pura /pm-kansio ../modules-hakemistoon. Asenna moduulin kautta Admin -> System Module -> Modules.

Yksityiskohtaiset ohjeet moduulien asentamisesta ovat saatavilla osoitteessa XOOPS-toiminnot Manuaalinen

KÄYTTÖOHJEET

Tämän moduulin määrittäminen edellyttää:

  • Syötät Saapuneet-kansioosi suoraan etusivulta tai napsauttamalla PM:n järjestelmänvalvoja-alueen ylälinkkiä "Siirry moduuliin".
  • Konfiguroi moduulin asetuksesi (katso "Asetukset") ja valinnaisesti PM-lohkoa, jos aiot käyttää sitä (katso "Blocks").
  • Voit poistaa viestisi massapoistoa käyttämällä "Pune" Messages" -välilehteä.

OHJEET

Opastus tulossa pian.
